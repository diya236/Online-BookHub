P# Project Statement

## Problem Statement
In many small book stores and student book shops, the process of buying books and checking available stock is still done manually. This makes the process slow, time-consuming, and sometimes inaccurate. Customers also find it difficult to know if a book is available or not. There is a need for a simple system that can manage books, search books, apply discounts, and handle purchase details in a fast and organized way.

## Scope of the Project
This project is designed to help users manage book records and perform basic operations in an online book store system. It allows adding, viewing, searching, and buying books. It also provides a discount feature on selected books. The system focuses on basic operations and provides a clean and simple structure for learning and real-life use. It can be expanded in the future with more features like login system, online payment, database storage, or GUI interface.

## Target Users
- Students who want to find books easily
- Small book store owners who need a simple management system
- Beginners learning Java and object-oriented programming
- Anyone who wants a basic system for book organization

## High-Level Features
- Add new books to the system
- Display all available books
- Search books by name
- Buy books and calculate total price
- Apply discounts on selected books
- Organized structure using different Java classes and modules
