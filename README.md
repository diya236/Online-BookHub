# Online Book Hub

Online Book Hub is a simple Java-based bookstore management system.  
It is created to understand how a basic online book store works.

### Overview
This project is designed using Core Java and Object-Oriented Programming concepts.  
It manages books, customers, orders, reviews, payments, wishlist and discount features.  
All operations run in the console and do not include a graphical interface.

### Features
- Admin and Customer system
- Inventory management
- Place orders and buy books
- Add and view book reviews
- Calculate average book ratings
- Payment processing
- Apply discount on purchase
- Wishlist feature

### Technologies Used
- Java
- Java Collections (ArrayList, List)
- DecimalFormat
- GitHub for version control

### How to Run the Project
1. Install Java JDK 8 or higher
2. Install any Java IDE (VS Code, IntelliJ, or Eclipse)
3. Download or clone the repository
4. Open the project folder in the IDE
5. Open the file `Bookstore.java` inside `src`
6. Run the program
7. The output will appear in the console

### Testing Instructions
- Add books and view inventory
- Place sample orders
- View reviews and average rating
- Try discount calculation
- Add and remove items from wishlist
